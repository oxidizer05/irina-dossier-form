# Анкета-досье — веб-страница для съёмки

Онлайн-анкета с досье на Ирину Фролову. Оператор (актёр в кадре) нажимает одну кнопку —
анкета заполняется «по буквам», как будто он печатает. Актёру достаточно делать вид,
что он набирает текст.

## Адрес в интернете

**https://oxidizer05.github.io/irina-dossier-form/**

Открывается на любом ноутбуке, планшете и телефоне, ничего скачивать не нужно.
Страница закрыта от поисковиков (`noindex`), но доступна всем, у кого есть ссылка.

Сайт обновляется сам через 1–2 минуты после `git push` в ветку `main`.

На площадке лучше открыть один раз заранее и **не закрывать вкладку** — так анкета
переживёт пропажу вайфая. Ещё надёжнее: браузер → «Сохранить страницу как…»,
и открывать локальную копию.

## Как запустить локально

Открыть `index.html` двойным кликом в браузере. Ничего устанавливать не нужно,
интернет не требуется (шрифты подгружаются из сети, но без них страница тоже
выглядит корректно).

Для съёмки: **F11** (Windows) / **Ctrl+Cmd+F** (Mac) — полноэкранный режим,
чтобы в кадр не попадали вкладки браузера.

## Кнопки (правый верхний угол)

| Кнопка | Что делает |
|---|---|
| **Автозаполнение** | Запускает печать. Повторное нажатие — пауза, ещё раз — продолжить с того же места. |
| **Сброс** | Мгновенно очищает всю анкету — можно начинать дубль заново. |
| **⌨ (клавиатура)** | Режим клавиш: печать идёт **от реальных нажатий актёра**. Он жмёт любые клавиши — на экране появляется следующая буква анкеты. Самый достоверный вариант для крупного плана рук. |
| **📱 / 🖥 (телефон-монитор)** | Переключает макет между телефонным и компьютерным. Иконка показывает, куда переключит: телефон — значит станет телефонный вид, монитор — вернёт компьютерный. Выбор запоминается в браузере. |
| **◐** | Светлая / тёмная тема. |
| **✕** | Спрятать панель кнопок, если она попадает в кадр. |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` / `Enter` | старт / пауза автозаполнения |
| `Esc` | сброс анкеты |
| `H` | спрятать / вернуть панель кнопок |

Если панель спрятана, а курсор не стоит в поле — управлять можно только с клавиатуры.

## Телефонная версия

Со смартфона ссылка открывается сразу в телефонном макете: шапка компактная,
фото и доход стоят в одну строку, остальные поля идут одной колонкой, а ряд
кнопок уезжает вниз — под большой палец. Поле «Ближайшие родственники» само
растёт под текст, так что все четыре строки видны целиком без прокрутки.

Кнопка **📱 / 🖥** нужна, когда макет надо задать вручную: например, показать
в кадре «анкету на телефоне», не выходя из ноутбука — страница сожмётся в
узкую колонку по центру экрана. Пока кнопку не нажали, макет выбирается сам
по ширине экрана; после нажатия он фиксируется и запоминается в этом браузере
(нажать ещё раз — вернётся обратно).

## Заполнение вручную

Все поля обычные: в них можно печатать руками, ставить и снимать галочки
у соцсетей и банков. Кнопки только очищают и заполняют — они ничего не блокируют.
Исключение: пока включён **режим клавиш**, ручной ввод отключён (каждое нажатие
выдаёт символ из сценария).

## Фото

Рамка «Фото» — кликните по ней или перетащите файл мышью, фото подставится сразу.

Фото Ирины уже лежит в репозитории — `assets/irina-2.jpg`, оно подгружается само
при открытии страницы, в том числе по ссылке на телефоне.

Чтобы заменить: положите новый файл в `assets/` под тем же именем (или укажите
другое имя в `data.js`, строка `photo:`) и запушьте — через 1–2 минуты обновится
и на сайте. Если файла нет — показывается серая заглушка `assets/placeholder.svg`.

При автозаполнении фото «проявляется» первым, со сканирующей полосой.

## Скорость печати

По умолчанию — «normal». Меняется прямо в адресной строке:

```
index.html?speed=slow     — медленно, для крупных планов
index.html?speed=normal   — по умолчанию
index.html?speed=fast     — быстро
```

Точные значения (мс на символ, разброс, пауза между полями) — в конце `data.js`,
блок `DOSSIER_SPEED`.

Дополнительно: `index.html?typos=1` — печать с редкими опечатками и их
исправлением (выглядит живее, но в кадре появляется ошибка на долю секунды).

## Где менять текст анкеты

Весь текст — в одном файле **`data.js`**: ФИО, дата, адреса, паспорт, телефон,
работа, доход, родственники, список соцсетей и банков, а также заголовок
документа. Порядок заполнения задаётся массивом `order`.

## Если правите файлы

В `index.html` стили и скрипты подключены с меткой версии (`styles.css?v=2`
и так далее). После правки `styles.css`, `app.js` или `data.js` увеличьте
это число во всех трёх строках — иначе браузер, который уже открывал анкету,
может подтянуть из кэша старую версию файла к новой странице.

Фото при замене под тем же именем обновляется у уже заходивших примерно
через 10 минут — если нужно сразу, дайте файлу новое имя и укажите его
в `data.js`.

## Экраны «Инструкции»

Кнопка **Инструкции** в ряду управления анкеты открывает вторую часть реквизита —
площадку, за которой «сидит» оператор. Три экрана, собраны по скриншотам из папки
`Materials` (сама папка в репозиторий не уходит, см. `.gitignore`).

| Страница | Что это |
|---|---|
| `hub.html` | Хаб со списком сервисов — плитки с иконками. Плитка либо ведёт на другой экран, либо открывает окно с документом. |
| `panel.html` | Панель оператора: четыре вкладки, столбцы кнопок-подсказок, поле информации о клиенте, список пунктов и текстовое поле. Нажатие любой подсказки подгружает в поле её текст. |
| `panopticon.html` | Админка: вход, группы, список прокси, таблицы статистики с вкладками. Цифры в таблицах живут сами — раз в пару секунд одна ячейка подрастает и подсвечивается. |

### Имитация работы

На каждом экране в панели управления есть кнопка **Имитация**. По ней запускается
сценарий: курсор ездит по экрану, наводится, нажимает кнопки, печатает в поля
по буквам, выделяет текст, листает страницу, переключает вкладки. Экраны связаны
в кольцо — хаб уводит в Panopticon, тот в панель оператора, та обратно в хаб,
и всё начинается заново. Можно оставить на мониторе и снимать сколько нужно.

**Ручной режим отдельно включать не надо.** Любое живое действие актёра — клик,
касание, прокрутка колесом — само ставит имитацию на паузу, и дальше он работает
руками: печатает в поля, жмёт подсказки, ходит по вкладкам. Пробел — продолжить
автоматику с того же места.

| Клавиша | Действие |
|---|---|
| `Пробел` / `Enter` | старт / пауза имитации |
| `Esc` | сброс: поля очищаются, экран возвращается в начало |
| `H` | спрятать / вернуть панель кнопок |

Скорость — тем же способом, что и у анкеты: `hub.html?speed=slow` (или `normal`, `fast`).
Адрес вида `hub.html?auto=1` запускает имитацию сразу при открытии — удобно, если
страницу выводят на экран заранее.

### Где менять текст

Всё содержимое трёх экранов — в одном файле **`zxc-data.js`**: плитки хаба, вкладки
и подписи кнопок панели, таблицы Panopticon, строка подвала.

Тексты документов и «сценариев» намеренно заменены на нейтральную рыбу: в кадре
это стена текста нужной длины и ритма, но пользоваться ей нельзя. Если для крупного
плана нужна конкретная формулировка — её набирают руками прямо на площадке, все поля
редактируются. В репозиторий такие тексты не кладём: он публичный и раздаётся как сайт.

Адреса прокси в таблице взяты из документационных диапазонов (192.0.2.x, 198.51.100.x,
203.0.113.x) — они ни на что не указывают.

## Файлы

```
index.html       — разметка анкеты
styles.css       — оформление анкеты (светлая и тёмная тема)
app.js           — движок печати, кнопки, горячие клавиши
data.js          — ВСЕ ДАННЫЕ АНКЕТЫ (правится только он)

hub.html         — хаб со списком сервисов
panel.html       — панель оператора
panopticon.html  — админка: вход, группы, прокси, статистика
zxc.css          — оформление трёх экранов выше
sim.js           — движок имитации: курсор, печать, выделение, панель кнопок
zxc-data.js      — ВСЕ ДАННЫЕ ЭТИХ ЭКРАНОВ (правится только он)

assets/          — фото
Materials/       — референсы, в репозиторий не уходят
```

Все данные вымышленные, страница — реквизит для съёмки. Никуда ничего не
отправляет, работает полностью локально.
