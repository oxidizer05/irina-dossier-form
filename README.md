# Анкета-досье — веб-страница для съёмки

Онлайн-анкета с досье на Ирину Фролову. Оператор (актёр в кадре) нажимает одну кнопку —
анкета заполняется «по буквам», как будто он печатает. Актёру достаточно делать вид,
что он набирает текст.

## Адрес в интернете

**https://oxidizer05.github.io/irina-dossier-form/**

Открывается на любом ноутбуке, планшете и телефоне, ничего скачивать не нужно.
Страница закрыта от поисковиков (`noindex`), но доступна всем, у кого есть ссылка.

Сайт обновляется сам через 1–2 минуты после `git push` в ветку `main`.

На площадке лучше открыть один раз заранее и **не закрывать вкладку** — так анкета
переживёт пропажу вайфая. Ещё надёжнее: браузер → «Сохранить страницу как…»,
и открывать локальную копию.

## Как запустить локально

Открыть `index.html` двойным кликом в браузере. Ничего устанавливать не нужно,
интернет не требуется (шрифты подгружаются из сети, но без них страница тоже
выглядит корректно).

Для съёмки: **F11** (Windows) / **Ctrl+Cmd+F** (Mac) — полноэкранный режим,
чтобы в кадр не попадали вкладки браузера.

## Кнопки (правый верхний угол)

| Кнопка | Что делает |
|---|---|
| **Автозаполнение** | Запускает печать. Повторное нажатие — пауза, ещё раз — продолжить с того же места. |
| **Сброс** | Мгновенно очищает всю анкету — можно начинать дубль заново. |
| **⌨ (клавиатура)** | Режим клавиш: печать идёт **от реальных нажатий актёра**. Он жмёт любые клавиши — на экране появляется следующая буква анкеты. Самый достоверный вариант для крупного плана рук. |
| **◐** | Светлая / тёмная тема. |
| **✕** | Спрятать панель кнопок, если она попадает в кадр. |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` / `Enter` | старт / пауза автозаполнения |
| `Esc` | сброс анкеты |
| `H` | спрятать / вернуть панель кнопок |

Если панель спрятана, а курсор не стоит в поле — управлять можно только с клавиатуры.

## Заполнение вручную

Все поля обычные: в них можно печатать руками, ставить и снимать галочки
у соцсетей и банков. Кнопки только очищают и заполняют — они ничего не блокируют.
Исключение: пока включён **режим клавиш**, ручной ввод отключён (каждое нажатие
выдаёт символ из сценария).

## Фото

Рамка «Фото» — кликните по ней или перетащите файл мышью, фото подставится сразу.

Фото Ирины уже лежит в репозитории — `assets/irina.jpg`, оно подгружается само
при открытии страницы, в том числе по ссылке на телефоне.

Чтобы заменить: положите новый файл в `assets/` под тем же именем (или укажите
другое имя в `data.js`, строка `photo:`) и запушьте — через 1–2 минуты обновится
и на сайте. Если файла нет — показывается серая заглушка `assets/placeholder.svg`.

При автозаполнении фото «проявляется» первым, со сканирующей полосой.

## Скорость печати

По умолчанию — «normal». Меняется прямо в адресной строке:

```
index.html?speed=slow     — медленно, для крупных планов
index.html?speed=normal   — по умолчанию
index.html?speed=fast     — быстро
```

Точные значения (мс на символ, разброс, пауза между полями) — в конце `data.js`,
блок `DOSSIER_SPEED`.

Дополнительно: `index.html?typos=1` — печать с редкими опечатками и их
исправлением (выглядит живее, но в кадре появляется ошибка на долю секунды).

## Где менять текст анкеты

Весь текст — в одном файле **`data.js`**: ФИО, дата, адреса, паспорт, телефон,
работа, доход, родственники, список соцсетей и банков, а также шапка документа
(название системы, номер дела). Порядок заполнения задаётся массивом `order`.

## Файлы

```
index.html   — разметка анкеты
styles.css   — оформление (светлая и тёмная тема)
app.js       — движок печати, кнопки, горячие клавиши
data.js      — ВСЕ ДАННЫЕ АНКЕТЫ (правится только он)
assets/      — фото
```

Все данные вымышленные, страница — реквизит для съёмки. Никуда ничего не
отправляет, работает полностью локально.
